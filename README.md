🏡 Airbnb Data Analysis
📄 Project Overview

This project explores Airbnb listings data using Python for data analysis and visualization. The goal is to uncover insights related to pricing trends, location-based performance, and host behavior patterns.

The analysis involves data cleaning, transformation, and visualization using Python libraries like Pandas, NumPy, Matplotlib, and Seaborn.

🚀 Objectives

Understand Airbnb pricing trends across different neighborhoods

Analyze factors affecting listing prices (location, reviews, availability)

Visualize the geographical distribution of Airbnb properties

Identify correlations between host activity and guest engagement

🧠 Key Steps

Data Loading:
Loaded dataset (compressed_data.csv) and handled data type inconsistencies.

Data Cleaning:

Removed missing and duplicate entries

Standardized categorical fields

Converted dates and numerical values properly

Exploratory Data Analysis (EDA):

Distribution of prices, availability, and reviews

Average pricing by neighborhood and room type

Correlation between review count and price

Host verification and its effect on bookings

Visualization:

Used Matplotlib and Seaborn for statistical charts

Created heatmaps and pair plots to identify relationships

Illustrated neighborhood-wise price distributions

📊 Technologies Used

Python 3

Pandas – for data manipulation

NumPy – for numerical computations

Matplotlib & Seaborn – for visualization

Jupyter Notebook – for interactive analysis


📈 Insights & Findings

Neighborhood significantly impacts listing prices.

Verified hosts tend to charge slightly higher rates.

Listings with frequent reviews have better visibility and higher occupancy.

Seasonal patterns affect availability and pricing.
